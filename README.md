# DriftLens

FYP: Development of an Agentic Artificial Intelligence System for Repairing and Validating Detection Rules Affected by Telemetry Changes

1. Create repository/folder structure.
2. Obtain the five Sigma rule files.
3. Collect/import baseline test telemetry.
4. Define machine-readable drift transformation files.
5. Implement Sigma rule execution/evaluation.
6. Implement baseline-vs-drift comparison.
7. Implement affected-rule evidence schema.
8. Run the five-rule pilot matrix.
9. Verify results manually.
10. Prepare Phase 1 output for supervisor review.
